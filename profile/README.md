## 🧠 Overview

PortraitPro is portrait retouching software from Anthropics Technology that ships both as a standalone application and as a plug-in for Photoshop and Lightroom. Sliders reshape the face, enlarge eyes, whiten teeth, remove blemishes and even out skin tones while the surrounding detail is preserved. It is developed by Anthropics Technology. The product family is positioned as a portrait retouching toolset for Windows workflows.

PortraitPro works as a plug-in suite on Windows 10 and Windows 11 and is installed alongside a host application such as Adobe Photoshop CC 2020 or newer.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🙂 Face Sculpting | Sliders for jawline, chin, nose, cheeks and eyes with the surrounding features kept in proportion. |
| 🧴 Skin Smoothing | Separates skin texture from blemishes, so pores survive while blotches disappear. |
| 💡 Relighting | Fills shadows and lifts under-eye areas without flattening the shape of the face. |
| 👁️ Eye and Mouth Tools | Enlarges eyes, removes red-eye, whitens teeth and adds catchlights. |
| 🌫️ Hair and Background | Masks hair and backdrop edges so distracting elements can be removed separately. |
| 🖼️ Batch Queue | Applies a saved preset to a folder of portraits and returns JPEG or TIFF files. |
| 🔄 Host Round-trip | Sends the edited portrait back to the host application as a new layer or file. |
